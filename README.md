A simple and responsive weather application that displays real-time weather information for any city.
Users can search for a city and instantly see:

🌡️ Current temperature
🌥 Weather condition & description
💧 Humidity
🤒 Feels-like temperature
🌤 Weather icon (auto updates with condition)

This project uses the OpenWeather API, async/await, and DOM manipulation to fetch and display live weather data. Invalid city names are handled gracefully with user-friendly messages.

Live link - https://ujwalweather-app.netlify.app
